# Қазақ мәдениеті

Бұл репозиторийдегі сайт `/uploads/Қазақ мәдениеті. Презентация.pdf` файлы негізінде жасалды.

## Ерекшеліктері

- Қазақ мәдениеті тақырыптары мәдени ерекшеліктер бойынша жеке бөлімдерге жіктелді.
- Әр бөлімді басқанда бөлім толық экранға ашылады.
- «Жабу» батырмасы бөлімді бастапқы карточка өлшеміне қайтарады.
- PDF-тегі мәтін бөлек блокпен берілді.
- PDF слайдтарының суреттері бөлімдерге түпнұсқа көрінісі ретінде қойылды.
- Барлық сайт мәтіні Lora қарпімен көрсетіледі.
