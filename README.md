# Қазақ мәдениеті

Бұл репозиторийдегі сайт қазақ мәдениеті туралы берілген материал негізінде жасалды.

## Ерекшеліктері

- Қазақ мәдениеті тақырыптары мәдени ерекшеліктер бойынша жеке бөлімдерге жіктелді.
- Әр бөлімді басқанда бөлім толық экранға ашылады.
- «Жабу» батырмасы бөлімді бастапқы карточка өлшеміне қайтарады.
- Негізгі мәтіндер 500–700 таңбалық түсіндірме форматында берілді.
- Көрнекі материалдарды да толық экранға шығарып, «Жабу» батырмасымен қайта жабуға болады.
- Көрнекі суреттер бөлімдерге тақырыптық материал ретінде қойылды.
- Барлық сайт мәтіні Lora қарпімен көрсетіледі.
